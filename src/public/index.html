Capabilities
Everything you need, nothing you don't
Structured template

Add project name, decision context, and priority focus to give Feedback Synthesiser the framing it needs to produce a sharper report.

Keep it simple mode

Toggle to collapse the form to a single text field — useful when you just have raw notes and no time to fill in details.

File upload

Upload transcripts directly — supports .txt, .md, .vtt, .srt, and .csv. Drag and drop onto the feedback area too.

Mock test data

Hit "Run test data" to stream a full mock report instantly — no API credits used. Useful for testing the interface.

Export as PDF or DOCX

Download the finished report in one click — PDF via the print dialog, or a properly formatted .docx file ready to share.
